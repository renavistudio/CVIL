# CVIL - Derecho Corporativo y Penal
Sitio web oficial de CVIL Abogados. Firma legal especializada en Derecho Corporativo, Penal y Blindaje Empresarial en Zamora, Michoacán.

## Stack Tecnológico
- React 19
- TypeScript
- Tailwind CSS
- Framer Motion
- Vite

## Desarrollo
\`\`\`bash
npm install
npm run dev
\`\`\`

## Producción
\`\`\`bash
npm run build
\`\`\`
